# Task Submission - Dhruv Jain

**What I built:**
A modern landing page for Async Labs featuring a scroll-driven background animation (240-frame sequence), smooth Lenis scrolling, a transparent sticky navbar, a hero section with brand integration badges, a "calm & focused" card section, and a features section with animated tabbed content and liquid glass morphing effects. Built with React, Tailwind CSS v4, Framer Motion, and Vite.

**How to view/use it:**
```bash
npm install
npm run dev
```
Then open http://localhost:3000 in your browser.
